iOS 앱이 카메라·사진·위치를 쓰려면 사용자에게 허락을 받아야 하고, 그때 뜨는 창에 들어갈 문구를 개발자가 써요. 대충 "카메라 권한이 필요합니다" 라고 쓰면 심사에서 5.1.1 Data Collection and Storage 로 돌아오기도 해요. 왜 필요한지가 없거든요.

심사자가 보는 것 — "그래서 뭘 하려고요?"

애플은 권한 문구가 그 데이터를 어디에 쓰는지 분명하고 빠짐없이 설명하길 요구해요. 예를 들면 이렇게요.

  • ✕ "카메라 권한이 필요합니다"
  • ○ "프로필 사진을 찍어 올리려면 카메라를 써요"
  • ✕ "위치 정보를 사용합니다"
  • ○ "내 주변 가게를 가까운 순으로 보여 주려고 현재 위치를 써요"

한 문장이면 돼요. 기능 이름이 들어가면 거의 통과합니다.

자주 같이 걸리는 것

  • 안 쓰는 권한 — 템플릿이나 라이브러리를 붙이다 보면 쓰지도 않는 마이크·연락처 권한 문구가 Info.plist 에 남아 있어요. 심사자는 "이걸 어디에 쓰냐"고 물어요. 안 쓰면 지우세요.
  • 첫 실행에 몰아서 묻기 — 앱을 켜자마자 권한 창이 서너 개 뜨면 사용자는 다 거부해요. 그 기능 버튼을 누를 때 물어보세요.
  • 거부하면 막히는 앱 — "권한을 허용해야 계속할 수 있어요" 로 앱을 막으면 안 돼요. 거부해도 그 기능만 빼고 쓸 수 있어야 하고, 나중에 설정에서 켜는 길을 알려 주면 돼요.
  • 문구가 아예 없음 — 문구 없이 카메라를 열면 심사 전에 앱이 그냥 꺼져요. 시뮬레이터에선 멀쩡해 보여도 실제 기기에서 꼭 눌러 보세요.

사진은 권한 없이도 돼요

사용자가 사진을 하나 골라 올리는 정도라면, iOS 의 시스템 사진 선택기(PHPicker)를 쓰면 사진 보관함 권한 자체가 필요 없어요. 고른 사진만 앱에 넘어오거든요. 권한 창이 하나 줄면 심사도 사용자도 편해요.

Expo·Flutter 에서는

  • Expo — app.json(app.config) 의 ios.infoPlist 나 각 라이브러리 플러그인 설정(예: 카메라 플러그인의 권한 문구)에 적어요. 기본 문구를 그대로 두면 영어 범용 문장이 나가요.
  • Flutter — ios/Runner/Info.plist 에 키와 문구를 직접 넣어요.

한국어 앱이면 문구도 한국어로 쓰세요. 영어·한국어를 다 내면 언어별 문구 파일(InfoPlist.strings)로 나눌 수 있어요.

권한 문구 체크리스트

  • 문구마다 '무엇을 하려고' 쓰는지 적었다
  • 앱이 실제로 쓰는 권한만 Info.plist 에 있다
  • 권한은 그 기능을 누를 때 묻는다 (첫 실행 X)
  • 거부해도 앱이 멈추거나 막히지 않는다
  • 사진 고르기만 하면 시스템 선택기로 권한 없이
  • Expo·Flutter 설정 파일에도 같은 문구가 들어갔다

마치며

권한 문구는 사용자에게 하는 부탁이에요. "필요합니다" 는 통보고, "사진 찍어 올리려고요" 는 부탁이죠. 부탁을 해야 허락도 잘 받아요 ㅎㅎ
