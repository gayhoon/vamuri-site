코드는 다 짰는데,
출시가 안 됩니다.

결제사 심사, 카카오 로그인, 약관, 배포, 요금 폭탄 — 코드 바깥에서 막히는 열 가지를 출시 전에 같이 끝냅니다. 저장소는 읽기만 하고, 리포트는 2~3영업일 안에.

00 / 어디서 막히나

보안 코드는 생각보다 잘 되어 있습니다.
비어 있는 건 돈·법·서버·관측입니다.

커뮤니티에서 반복되는 다섯.

01 결제

심사가 안 넘어간다

토스/포트원 연동 · 웹훅 · 환불 규정이 코드·약관·화면에서 제각각

02 인증

가입 경로가 안 열린다

카카오·네이버 로그인, 본인인증, 문자 인증 — 운영에서 실제로 열리는 게 하나도 없는 경우

03 배포

설정 하나에 전부 403

도메인·HTTPS·환경 분리·권한. 운영 설정 하나가 빠져 부팅이 안 되거나 모든 요청이 막히는 구성

04 법규

자리표시자가 공개된다

처리방침·약관·통신판매업·동의 — "[확정 대기]" 인 채 공개, 효력일이 거꾸로 된 개정판

05 비용·운영

알림이 없어 요금 폭탄

백업 없음, CI 분 소진, 첫 관리자를 운영에서 만들 길이 없는 콘솔

01 / 무엇을 보나

출시 경로 10묶음

14영역 79항목을 출시를 막는 순서대로 묶었습니다. 항목마다 통과 / 문제 / 해당없음 / 미확인을 근거(파일·줄)와 함께, 미확인은 확인 방법까지.

  1. 사업자·서류 — 통신판매업, 사업자 정보 표시, 실 도메인
  2. 결제 — PG 선정 → 어댑터 → 웹훅 → 대사(對査). 운영 기본값이 결제를 끄지 않는가
  3. 환불 규정 — 코드·약관·결제 전 고지가 같은가, 누가 환불을 집행하는가
  4. 배포 실물 — 도메인·HTTPS·헬스체크·롤백
  5. 운영 설정 정합 — 환경변수와 부팅 검사, 정책값이 결정값인가
  6. 가입·로그인 경로 — 메일·문자·소셜 중 운영에서 실제로 열리는 것
  7. 약관·처리방침·고지 — 값·조항·효력 순서
  8. 관측·백업·비용 — 장애를 알 수 있고 되돌릴 수 있는가
  9. 목업 숨김·판매자 쓰기 — 시안이 실 사용자에게 안 보이는가, 운영 당사자가 쓸 수 있는가
  10. 로그 개인정보·복구 경로·동시성 — 증명까지

배포가 먼저입니다. PG 심사 URL, 웹훅 주소, 소셜 로그인 콘솔, 메일 도메인 인증, 실기기 테스트가 전부 실 도메인을 요구합니다. 그래서 외부 의존은 첫날 착수하고, 코드는 배포 실물부터 합니다.

02 / 어떻게 하나

신청부터 권한 회수까지

  1. 신청 폼 — 5분. 48시간 안에 무료 진단 결과 또는 대기 순번
  2. 접근 방식 선택 — 읽기 권한 제공 또는 "코드 비공개". 어느 쪽이든 비밀유지약정이 먼저
  3. 읽기 전용 진단 — 기준 커밋을 고정하고 브랜치·커밋을 만들지 않습니다
  4. 리포트 — 항목마다 판정 + 근거 파일:줄 + 미확인은 확인 방법
  5. 우선순위 회의 60분 — 차단 / 권장 / 후순위를 같이 정합니다
  6. (출시 패키지) 수정 — 카드 1장 = PR 1개, UI 는 그대로, 머지는 여러분이
  7. 운영 문서 셋과 권한 회수 확인서 — 런북 · 계정 대장 · 시크릿 대장

AI 가 읽고, 사람이 판정합니다. 어떤 도구를 쓰는지, 코드가 어디로 가는지 개인정보 처리방침에 적어 두었고, 입력을 학습에 쓰지 않는 조건의 서비스를 씁니다.

03 / 최근 진단

예약형 서비스 한 곳, 출시 전 전수 진단

권한 검사, 비밀번호 해시, 입력 검증, 같은 자리 중복 판매 방지는 전부 통과였습니다. 비어 있던 것은 코드가 아니라 — 운영 설정 두 줄이 빠져 모든 호출이 403 이 되는 구성, 메일 공급자가 없어 운영 기동 자체가 불가능한 상태, 판매자 콘솔에 가짜 정산 숫자가 기본 메뉴로 들어간 것, 약관이 자리 표시자인 채 공개된 것이었습니다. 사례는 동의를 받은 것만, 익명으로만.

04 / 가격

지금은 무료 기간입니다

서비스를 다듬는 기간이라 산출물은 정가와 같습니다. 유료 전환일은 최소 30일 전에 메일로 알리고, 진행 중인 건은 무료로 끝냅니다.

상품내용정가무료 기간
무료 진단준비물 표 + 출시 경로 10묶음 판정, 1쪽. 신청 뒤 48시간 안0원무료 (계속)
상세 진단79항목 리포트 + 수정 제안 + 회의 60분. 2~3영업일, 주 2팀390,000원무료
출시 패키지상세 진단 + 배포·설정·관측·목업·로그 수정 + 외부 동행 + 운영 문서 셋. 2~4주2,900,000원~선착순 3팀 무료
월 유지보수출시 뒤 운영 점검과 수정390,000원/월전환 뒤

옵션(정가): 결제 연동 +1,500,000 · 법규 문안 초안 +500,000 · 인증 공급자 연동 +300,000/종. 무료 기간 신청자는 전환 뒤 첫 결제 30%.

05 / 약속

코드를 맡기기 전에 알아야 할 것

  • 비밀유지약정이 먼저 — 저장소를 열기 전에 씁니다
  • 읽기 전용 — 진단 중 브랜치·커밋·파일을 만들지 않습니다
  • 코드가 내 기계를 떠나지 않는 선택지 — "코드 비공개" 를 고르면 질문지와 안내문을 드리고 분석은 여러분 기계에서
  • UI 는 그대로 — 수정은 설정·배포·결제·법규·운영 쪽
  • 종료 후 권한 회수 확인서
  • AI 사용과 전송 경로 공개 — 처리방침에 적어 둡니다
  • 참고 자료이지 법률 자문이 아닙니다 — 법규 항목은 확인해야 할 질문 목록을 같이 드립니다
  • 결과물은 여러분 것 — 저장소에 들어간 변경은 여러분 소유, 사례는 별도 동의·익명으로만

06 / FAQ

자주 묻는 것

코드를 꼭 보여줘야 하나요?

아니요. 읽기 권한을 주시면 더 깊이 보지만, "코드 비공개" 를 택하면 질문지와 안내문을 드리고 분석은 여러분 기계에서 돌립니다. 어느 쪽이든 비밀유지약정이 먼저입니다.

AI 가 하나요?

네, AI 가 읽고 사람이 판정·검수합니다. 어떤 도구에 무엇이 전송되는지 처리방침에 적어 두고, 입력을 학습에 쓰지 않는 조건의 서비스를 씁니다.

다른 "출시 점검" 서비스와 뭐가 다른가요?

점검 항목은 비슷합니다. 다른 건 범위입니다 — 결제사 계정 설정, 인증 공급자 연동, 배포 실물, 법규 문안처럼 보통 "별도 견적" 으로 빠지는 것을 기본 범위에 넣습니다. 그리고 항목마다 근거(파일·줄)와 미확인 항목의 확인 방법을 드립니다.

무료 기간이 끝나면요?

유료 전환일을 최소 30일 전에 메일로 알립니다. 진행 중인 건은 무료로 끝내고, 무료 기간 신청자는 첫 결제 30% 혜택을 받습니다.

결제사(PG) 계약도 해 주나요?

계약·서류는 대표자가 직접 해야 하지만, 서류 준비·심사용 사이트 요건(약관·처리방침·사업자 정보가 떠 있는 실 URL)·어댑터·웹훅·환불 구현은 저희가 합니다.

법률 자문인가요?

아닙니다. 약관·처리방침은 초안과 함께 확인해야 할 질문 목록을 드립니다. 변호사 검토를 원하시면 그 목록을 그대로 쓸 수 있고, 최종 판단과 책임은 여러분에게 있습니다.

어떤 스택이든 되나요?

웹 서비스면 됩니다. 확인 방법은 스택 중립으로 쓰여 있고, 처음 보는 스택은 저장소 지도를 먼저 만듭니다. 앱 스토어 심사는 범위 밖입니다.

얼마나 걸리나요?

상세 진단 2~3영업일(주 2팀, 대기열 안내). 출시 패키지 2~4주 — 외부 의존(PG 심사·계정)이 길어지면 그만큼 늘어나고, 그 전에 끝낼 수 있는 배포·설정부터 합니다.

수정하면 화면이 바뀌나요?

UI 는 그대로 둡니다. 바꾸는 건 설정·배포·결제·법규·운영 쪽입니다. 모든 변경은 PR 로 가고 여러분이 머지합니다.

결과물은 누구 것인가요?

여러분 저장소에 들어간 변경은 여러분 것입니다. 저희 체크리스트와 절차는 저희 것이고, 사례로 쓰는 건 별도 동의가 있을 때만, 익명으로만 합니다.
